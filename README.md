# System Monitoring Agent

Лёгкий фоновый агент для мониторинга активности пользователя и отправки собранных данных на локальный HTTP-сервер.

## Возможности

- сбор данных каждые 5 секунд;
- определение активного процесса;
- определение заголовка активного окна;
- определение активности пользователя за интервал сбора;
- упаковка накопленных данных каждые 30 секунд или при накоплении 10 записей;
- отправка JSON-пакетов на HTTP-сервер;
- сохранение неотправленных данных на диск при недоступности сервера;
- автоматическая повторная отправка сохранённых пакетов после восстановления соединения;
- ограничение общего количества сохранённых и ожидающих отправки записей — 100;
- сохранение неотправленных данных при завершении работы агента;
- вывод основных событий работы агента в консоль.

## Требования

- Windows
- C++17
- CMake 3.20 или новее
- Visual Studio 2022 с поддержкой C++
- Python 3 для запуска тестового HTTP-сервера

## Сборка

Создайте директорию для сборки:

~~~powershell
mkdir build
cd build
~~~

Сгенерируйте проект CMake:

~~~powershell
cmake ..
~~~

Соберите Release-версию:

~~~powershell
cmake --build . --config Release
~~~

После успешной сборки исполняемый файл будет находиться здесь:

~~~text
build/Release/SystemMonitoringAgent.exe
~~~

## Запуск

Для тестирования отправки данных используется локальный HTTP-сервер, реализованный в `server.py`.

Сначала запустите сервер:

~~~powershell
python server.py
~~~

После этого запустите агент:

~~~powershell
./build/Release/SystemMonitoringAgent.exe
~~~

Агент будет работать в фоновом режиме и выводить основные события в консоль.

Для завершения работы агента используется клавиша `Esc`.

## Хранение данных

При недоступности HTTP-сервера сформированные пакеты сохраняются в директории:

~~~text
storage/
~~~

После восстановления соединения агент автоматически пытается отправить сохранённые пакеты на сервер.

Количество записей, находящихся в памяти и на диске, ограничено 100 записями.

## Формат данных

Агент отправляет JSON следующего вида:

~~~json
{
  "agent_id": "DESKTOP-MIDDLE-C",
  "timestamp": "2026-09-26T12:00:00",
  "payload": [
    {
      "time": "2026-09-26T11:59:55",
      "process_name": "example.exe",
      "window_title": "Example Window",
      "user_active": true
    }
  ]
}
~~~

## Архитектура

Проект разделён на несколько основных компонентов:

- **Collector** — собирает метрики и помещает их в буфер.
- **Buffer** — хранит собранные записи в памяти.
- **Packer** — формирует JSON-пакеты и управляет их отправкой или сохранением.
- **Sender** — отвечает за HTTP-взаимодействие с сервером.
- **DiskStorage** — сохраняет неотправленные пакеты на диск.
- **server.py** — простой локальный HTTP-сервер для тестирования агента.
